# Student Grade Project

This project contains three simple C programs based on student marks and grades.

## Files

* grade.c – Takes marks  and show the grade.
* comment.c – Takes marks, show the grade, and gives a comment according to the grade.
* eligibility.c – Takes marks, displays the grade, and checks whether the student is eligible for the next level.

## Concepts Used

* Variables
* if-else statements
* else-if ladder
* operator
* switch-case
* scanf() and printf()
* Character variables
* Basic conditions and comparison operators

## Purpose

This project is created for practicing basic C programming concepts using a simple student grading system.

## How to Run

1. Open the C file in any C compiler or VS Code.
2. Compile the program.
3. Run the program.
4. Enter the student's marks.
5. The program will show the grade and related result.
